# 04 Networking

My network labs are in their own repo, with screenshots, config files and the Packet Tracer files:

**[network-labs](https://github.com/sreza0134-dev/network-labs)**

| Lab | What it covers | Tool |
|---|---|---|
| 1. Office network with VLANs | Three VLANs, routing between them, DHCP, NAT, and an access list that blocks guests | Packet Tracer |
| 2. Fix the broken network | Finding and fixing five network faults | Packet Tracer |
| 3. See the traffic | Looking at real ARP, DHCP, DNS, ping and TCP packets | Wireshark |
| 4. Two offices joined by a **VPN** | An encrypted IPsec tunnel between two offices | Packet Tracer |
| 5. Switch security | SSH, port security and shutting unused ports | Packet Tracer |
