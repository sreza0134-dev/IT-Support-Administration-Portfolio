# Scenario 6: Slow computer

Level: Basic
Note: Practice scenario. The details are fictional.

## Problem
A user's Windows laptop has become very slow. Programs take a long time to open and the fan is loud.

## Symptoms
- Slow start-up and slow programs
- The fan runs loudly
- It started a few days ago, after a new program was installed

## Diagnostic steps
1. Ask what changed. A new program, an update, or a new file can all matter.
2. Open Task Manager. Check which program uses the most CPU and memory.
3. Check disk space. Low free space slows Windows down a lot.
4. Check the programs that start with Windows (Startup tab in Task Manager).
5. Check for pending Windows updates and for malware with Windows Security.

## Root cause
The laptop had only 3 percent free disk space, and a heavy program started with Windows every time.

## Solution
1. Free up disk space: empty the recycle bin, remove programs not needed, and clear temporary files
2. Turn off the heavy program in the Startup tab
3. Restart the laptop and check Task Manager again
4. Ask the user to confirm it feels faster

## Prevention
- Keep at least 15 percent of the disk free
- Review start-up programs when installing new software
- Check on laptops with older hardware and consider more memory or a faster drive

## What I learned
Task Manager shows quickly what slows a computer down. Check there before reinstalling anything.
