# Helpdesk Tickets 001 to 005

Practice tickets. All names and details are fictional.

## INC-001: Locked out after wrong password
- Date: 2026-10-05
- Priority: Medium
- Impact: One user, cannot work
- Category: Account access
- Issue: User is locked out after typing the wrong password several times.
- Steps taken: Verified identity with name and employee ID. Checked the account in the admin center: locked, license active. Unlocked it and reset the password, forced a change at next sign-in.
- Resolution: User signed in and set a new password.
- Time to resolve: 10 minutes
- Follow-up: Told the user about Self-Service Password Reset.

## INC-002: Can't sign in after getting a new phone
- Date: 2026-10-06
- Priority: High
- Impact: One user, client meeting in one hour
- Category: Account access (MFA)
- Issue: The sign-in asks for approval in the Authenticator app, which is still on the old phone.
- Steps taken: Verified identity. Checked sign-in logs: stopped at the MFA step. Gave a Temporary Access Pass.
- Resolution: User signed in, set up the Authenticator app on the new phone, and the old phone was removed.
- Time to resolve: 20 minutes
- Follow-up: Asked the user to add a second sign-in method.

## INC-003: Printer down for the whole second floor
- Date: 2026-10-07
- Priority: High
- Impact: About 15 users
- Category: Hardware and network
- Issue: Nothing prints. The printer shows an error code.
- Steps taken: Noted the error code. Checked paper, toner, and jams. Power cycled the printer. Pinged its IP address: replies. Found a stuck job in the print queue.
- Resolution: Cleared the stuck job and sent a test page.
- Time to resolve: 25 minutes
- Follow-up: Reminded users not to resend a job repeatedly.

## INC-004: Request to install Zoom
- Date: 2026-10-08
- Priority: Low
- Impact: One user, can work without it
- Category: Software request
- Issue: User needs Zoom for a customer call next week.
- Steps taken: Checked that Zoom is on the approved software list. Got manager approval. Installed it and tested a call.
- Resolution: Zoom installed and working.
- Time to resolve: 30 minutes
- Follow-up: None.

## INC-005: New employee setup
- Date: 2026-10-09
- Priority: Medium
- Impact: One new hire, starts Monday
- Category: Onboarding
- Issue: New employee needs a laptop and accounts before the first day.
- Steps taken: Created the user and assigned a Microsoft 365 license. Added the user to the right security group. Set up MFA. Installed the standard software. Tested sign-in.
- Resolution: Laptop and accounts ready on Friday afternoon.
- Time to resolve: 90 minutes
- Follow-up: Gave the manager a short first-day guide.
