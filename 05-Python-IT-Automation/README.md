# Python IT Automation

Two Python tools that automate common IT support work, both built with the Gemini API.

## AI Ticket Triage Bot

Reads support tickets from a CSV file and sorts each one by category and priority. It suggests a first response and decides if the ticket needs a human. It retries automatically when the API is busy.

https://github.com/sreza0134-dev/ticket-triage-bot

## AI Helpdesk Assistant

A chatbot that answers IT questions by searching a knowledge base first, then answering from the document it finds (RAG). If nothing matches well, it says so and suggests a human agent.

https://github.com/sreza0134-dev/ai-helpdesk-assistant
