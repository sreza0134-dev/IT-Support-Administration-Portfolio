# Microsoft 365 Lab

A hands-on lab where I set up and administered a Microsoft 365 Business Premium tenant from scratch.

## What I covered

- Created users and assigned licenses
- Built a security group and used it in policies
- Set up a Conditional Access policy that requires MFA
- Enabled Self-Service Password Reset
- Configured the Apple MDM Push Certificate and enrolled a real iPhone in Intune
- Created an iOS compliance policy
- Improved the Microsoft Secure Score from 39.93% to 42.09%
